# Sanjeda Nasrin Tosiba — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, colors, responsive styling and visual details
- `script.js` — mobile navigation and current footer year
- `profile.jpg` — profile photograph

## Run locally
Open `index.html` in a web browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `tosiba-portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will publish the site and show its public URL.

## Before publishing
The supplied profile photograph is used in the hero section. Confirm the phone, email, LinkedIn, GitHub and Facebook links before publishing. The Facebook share link is included as a social link, but its profile details were not independently accessible.
